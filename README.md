# Welcome to Drill Diver
A speedrunning platformer with a drill. You play as Experiment 1257 or Bit! Bit has a drill for an arm and can use it to dash through the air and burrow underground. Use your drill to dash through enemies, launch in and out of the ground, and finish levels as fast as possible! This is a showcase of the mechanics and ideas in the project, featuring a tutorial level, 3 levels, and a level editor! So get drilling and aim for those S Ranks!

Some things worth mentioning:
- Controller is the preferred input device for this game, but keyboard is fine.

- Level Editor cannot be done with a controller.

- There should be no specific instructions to run; just launch!

- There are Godot addons used in the creation of this game; Dialogic,  BetterTerrain, and ControllerIcons

- There is a tutorial level plus multiple different levels to play and enjoy
